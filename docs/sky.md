# Небо (Sky)

Необязательный фон, который следует за часами: ночные синие тона до рассвета, мягкий голубой день,
а затем тёплый горизонт, достигающий пика около восьми вечера. Во встроенной конфигурации он
выключен, поэтому лаунчер, собранный из этого репозитория, ведёт себя в точности как раньше, пока
тема его не включит.

```json
{ "sky_intensity": 60 }
```

![Фон в сумерках, за несколько минут до восьми](sky-sunset.jpg)

Передайте это как `config.json` темы и перезапустите Home:

```bash
TV_HOST=192.168.1.50 tools/theme.sh themes/your-theme
```

## Что он рисует

Полноэкранный градиент из трёх полос — верхняя, средняя, нижняя — с мягким тёплым свечением у
горизонта, чьё горизонтальное положение следует за солнцем: слева на восходе, справа на закате.
`sky_intensity` — его непрозрачность, от 0 до 100; сами цвета интерполируются между несколькими
опорными точками в течение суток — именно поэтому фон плавно дрейфует, а не переключается в
фиксированные часы.

Фон лежит позади всего и поверх обоев, если они есть; палитра выбрана тёмной намеренно: белые
часы, приветствие, имя приложения и полоса дока сохраняют контраст при значении по умолчанию 60.

## Цена

`Sky` — чистая математика: без типов Android и без собственных часов; вызывающий код передаёт
минуты, прошедшие с полуночи, — поэтому палитра покрыта unit-тестами на JVM. `SkyView` рисует один
битмап 480×270 и перерисовывает его раз в минуту, тем же минутным тиком, что обновляет часы. Ничего
не анимируется и ничего не требуется: фон — единственное изменение, и телевизору с 1 ГБ ОЗУ не за
чем гоняться.

Выключение ключа возвращает обычный фон (или `wallpaper`/`background_color` темы) при следующем
запуске Home.
