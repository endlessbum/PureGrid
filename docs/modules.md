# Создание модуля

Модуль — обычное приложение для Android TV, которое объявляет карточку для этого лаунчера. Ваш
репозиторий, ваша лицензия, ваш ключ подписи; выпускайте APK где угодно, например на своей
странице GitHub Releases вместе с SHA-256. Владелец телевизора устанавливает его как любое другое
приложение (sideload). Лаунчер находит карточку и один раз спрашивает владельца; если тот отвечает
«Показать», приложение с этого момента отображается карточкой: ваше название, необязательная
подпись и ваш цвет в ambient-свечении — впереди алфавитной сетки.

Контракт описан в [`docs/specs/card.md`](specs/card.md). Эта страница — краткая версия.

## 1. Объявите карточку

В activity, у которой уже есть фильтр `LEANBACK_LAUNCHER`, добавьте второй фильтр и запись
`meta-data`:

```xml
<activity android:name=".LibraryActivity" android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LEANBACK_LAUNCHER" />
    </intent-filter>
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="com.gathin.tvhome.category.DOCK_CARD" />
    </intent-filter>
    <meta-data android:name="com.gathin.tvhome.card" android:resource="@xml/module_card" />
</activity>
```

Затем создайте `res/xml/module_card.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<card spec="1" label="Retro" caption="NES games" accent="#E8A33D" />
```

- `label`: от 1 до 24 символов — буквы, цифры, пробел и `. & + ' -`. Делайте коротко: это имя
  плитки и верхней полки. Слова вроде «verified» или «official», собственные имена интерфейса
  лаунчера и названия входов (например, HDMI) отклоняются, как и новая карточка, чьё название
  (или название её приложения) совпадает с именем другого установленного на ТВ приложения (полный
  список — в спецификации). Смена названия в обновлении заставляет владельца решать заново, поэтому
  выбирайте его один раз.
- `caption`: необязательная, до 32 символов, показывается после названия, когда карточка в фокусе.
  Слова поддержки («verified», «official»), запрещённые в названиях, запрещены и здесь. Строка имени
  под плиткой одна; название и подпись вместе занимают около 26 символов в сетке из 4 колонок,
  поэтому подпись — пара слов.
- `accent`: необязательный `#RRGGBB` — цвет свечения за карточкой, пока она в фокусе в доке.
- Пишите значения как буквальный текст. Ссылки `@string` в спецификации 1 не разрешаются.

Карточка должна висеть на той же activity, что и ваш фильтр `LEANBACK_LAUNCHER`, и эта activity
должна быть exported и включена. Иначе карточка отбрасывается.

## 2. Держите модуль лёгким

Лаунчер рассчитан на телевизоры с 1 ГБ ОЗУ, и владельцы доверяют тому, что ставят на домашний
экран.

- Никаких фоновых сервисов, если функциональность их не требует, — а если требует, скажите об
  этом в README.
- Никакой телеметрии без явного согласия. Никакой рекламы.
- Не включайте контент, на распространение которого у вас нет прав.
- Используйте собственную графику. Не используйте чужие логотипы как баннер или иконку.
- Опишите каждое запрашиваемое разрешение в своём README.

## 3. Проверьте на телевизоре

Установите по ADB, нажмите Home — появится запрос:

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
adb shell input keyevent KEYCODE_HOME
```

(`tools/tv.py` из этого репозитория выручает там, где бинарник `adb` заблокирован; см. README.)

Полезные проверки:

```bash
# Фильтр карточки и meta-data попали на нужную activity?
adb shell pm dump io.github.udhaykumarbala.retro | grep -B2 -A6 DOCK_CARD

# Почему карточка отклонена? Одна строка на каждую причину.
adb logcat -s TvHomeCards
```

Дальше: ответьте «Оставить скрытой» и проверьте, что приложение сохраняет обычную плитку; зажмите
OK на «Настройках», откройте список «Карточки модулей», переключите в «Показана» и проверьте, что
карточка заняла место плитки; нажмите OK на карточке и проверьте, что приложение открывается;
удалите приложение и проверьте, что карточка исчезла. Снимок карточки в фокусе в сетке приложите
к своему README.

## 4. Публикация и хранение ключа

Ответ владельца привязан к вашему сертификату подписи. Публикуйте дайджест сертификата с каждым
релизом, чтобы люди могли проверить то, что устанавливают:

```bash
apksigner verify -print-certs app-release.apk | grep 'SHA-256'
```

(`apksigner` принимает свои опции и с одним, и с двумя дефисами.)

Строка «Signer #1 certificate SHA-256 digest» — это то, что лаунчер вычисляет на телевизоре.
Подписывайте каждое обновление тем же ключом: другой ключ заставит каждый телевизор спросить
заново, и карточка останется скрытой, пока владелец не ответит. Подписывайте одним сертификатом:
APK с несколькими подписантами лаунчер отклоняет. Храните keystore вне репозитория.

Рядом с APK публикуйте и его собственный SHA-256.
